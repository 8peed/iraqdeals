# IraqDeals — نسخة أولى شغالة

مشروع Next.js حقيقي متصل بقاعدة بيانات Supabase. فيه:
- عرض الصفقات من قاعدة بيانات فعلية
- تسجيل دخول / إنشاء حساب (إيميل + كلمة مرور)
- نشر عرض جديد (يحفظ بالقاعدة فعلياً)
- تصويت (مفيد / منتهي) لكل عرض

## خطوات التشغيل

### 1. إنشاء مشروع Supabase (مجاني)
1. روح إلى supabase.com وسوّي حساب
2. اضغط **New Project**، اختار اسم وكلمة مرور لقاعدة البيانات
3. بعد ما يجهز المشروع، روح لـ **SQL Editor** من القائمة الجانبية
4. افتح ملف `supabase/schema.sql` من هذا المشروع، انسخ محتواه كامل، الصقه بمحرر SQL بسوبابيس، واضغط **Run**
5. روح لـ **Settings -> API**، وانسخ:
   - **Project URL**
   - **anon public key**

### 2. إعداد المتغيرات البيئية
1. سوّي نسخة من ملف `.env.example` وسمّها `.env.local`
2. الصق فيها القيم اللي نسختها من Supabase

### 3. التشغيل محلياً
```bash
npm install
npm run dev
```
افتح المتصفح على `http://localhost:3000`

### 4. النشر أونلاين (Vercel)
1. ارفع المشروع لمستودع على GitHub
2. روح لـ vercel.com وسوّي حساب، واختار **Import Project** من GitHub
3. بقسم **Environment Variables** بـ Vercel، ضيف نفس المتغيرين من `.env.local`
4. اضغط **Deploy**
5. بعد ما ينشر، روح لإعدادات المشروع بـ Vercel -> **Domains** -> أضف الدومين اللي اشتريته واتبع تعليمات ربط DNS

## الخطوات الجاية (تدريجياً)

- صفحة متجر مستقلة لكل متجر
